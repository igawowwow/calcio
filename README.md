# ヴィレキャリア 🌸

未経験からの転職・はじめてのキャリアチェンジを専門にサポートする、キャリア支援サービス「ヴィレキャリア」の公式サイトです。

未経験者の方が安心して飛び込めるよう、アニメ・漫画風のキャラクターイラスト(すべて手描きのインラインSVG)を多用した、明るくポップなトーンで全面リニューアルしました。

## 構成

- **ヒーロー**:キャッチコピー「経験ゼロは、伸びしろ∞。」+ アドバイザーのイラスト
- **モヤモヤあるある**:未経験転職の悩みを吹き出しで共感
- **選ばれる3つの理由**:未経験OK求人の厳選 / 専属アドバイザー / 完全無料サポート
- **アドバイザー紹介**:蒼井 蓮・桜井 美桜・日向 朱莉・白瀬 仁 の4人のキャラクターカード
- **内定までの4ステップ**:登録 → 面談 → 選考対策 → 内定・入社後フォロー
- **求人情報**:倉庫・物流を中心とした未経験OK求人カード(`src/jobs.ts` に追記するだけで掲載)
- **先輩の声**:未経験から転職した3人の体験談
- **お役立ち記事**:記事一覧+記事ページ(`#/article/記事ID` のハッシュルーティング)。`src/articles.ts` に追記するだけで一覧カードと記事ページが自動生成されます
- **FAQ / CTA**:よくある質問と無料相談への導線

## 技術

- React 19 + TypeScript + Vite
- 依存ライブラリなしの手書きCSS(ポップなステッカー風デザインシステム)
- キャラクターは `src/characters.tsx` のSVGコンポーネント(パレット差し替えで人物バリエーションを生成可能)

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 本番ビルド
npm run preview  # ビルドのプレビュー
npm run lint     # lint
```

## デプロイ

対象ブランチへの push で GitHub Actions が `dist/` を `gh-pages` ブランチへ公開します。
